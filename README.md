# My AI Agent

A personal AI agent that I'm building while learning AI engineering.

## Current Features

- Python backend
- Gemini API
- REST API fundamentals
- LLM integration
- Embeddings
- ChromaDB vector database
- Semantic search
- PDF text extraction
- Document chunking
- RAG pipeline

## Architecture

User
↓
AI Agent
↓
Gemini
↓
RAG
↓
ChromaDB
↓
Relevant Documents
↓
Response
